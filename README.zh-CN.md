# quota-compact

[English](README.md) | 简体中文

一个 Claude Code 插件：账号的 **5 小时额度** 用到你设定的百分比（默认 98%）时，在**会话运行中**自动压缩上下文。如果有回合正在进行，插件会在安全点暂停它，压缩上下文，再让 Claude 从中断处继续。

## 功能

- **按 5 小时额度触发**，不看上下文大小。读取的是状态栏显示的同一份用量数据。
- **暂停 → 压缩 → 恢复**：回合正在运行时，插件在安全点结束回合，也就是当前工具调用执行完、模型还没发出下一次请求的时候。正在运行的命令、写到一半的文件都不会被截断。压缩后自动发一条消息，让 Claude 继续之前的任务。
- **子代理不阻塞**：插件启用期间，主会话新启动的子代理改为在后台运行。主会话可以照常暂停和压缩，子代理继续工作。
- **每个窗口只触发一次**：每个会话在每个 5 小时窗口里最多压缩一次，窗口重置后才会再次生效。
- **设置永久保存**：`/quota-compact` 用来开关和设置百分比。设置对所有会话生效，重开会话后保持不变，和 `/autocompact` 一样。

## 使用条件

- 支持插件的 Claude Code
- Claude 订阅账号（Pro / Max）。5 小时额度数据只在订阅账号登录时提供，使用 API key 时插件不会做任何事。

## 安装

在 Claude Code 终端会话的输入框里输入：

```
/plugin install quota-compact --marketplace hxy920830/quota-compact
```

提示添加市场时输入 `y`，再按回车选择用户范围。

在命令行里安装：

```
claude plugin install quota-compact --marketplace hxy920830/quota-compact
```

桌面版 App 里不能运行 `/plugin`：点输入框旁边的 **+**，选 **Plugins**，用 **Add marketplace** 添加 `hxy920830/quota-compact`，再点 **Add plugin**。

## 用法

| 命令 | 作用 |
| --- | --- |
| `/quota-compact` | 查看当前设置和 5 小时额度用量 |
| `/quota-compact on 95` | 启用，阈值设为 95% |
| `/quota-compact off` | 停用 |
| `/quota-compact on` | 启用，保持原阈值 |
| `/quota-compact 90` | 只改阈值 |

- 开关也可以写成 启用/停用、开启/关闭、enable/disable、true/false、1/0。
- 百分比范围 1–100，支持一位小数，例如 `97.5`。
- 回合进行中也能直接输入这个命令，不用等。
- 如果设置后当前额度已经超过新阈值，会立即开始压缩。

## 工作原理

1. 每次拿到用量数据时，插件检查 `five_hour` 窗口有没有达到阈值。
2. 会话空闲时，直接压缩，和 `/compact` 一样。
3. 回合运行中时，等到下一个安全点结束回合，压缩后发送恢复消息。
4. 压缩被拒绝时，每 3 秒重试一次，最多约 1 小时。

## 限制

- 单个很长的工具调用（比如一条要跑 10 分钟的命令）会先执行完才暂停，不会被强行中止。
- 插件加载之前就已经在前台运行的子代理，仍会让主回合等它返回。
- 插件启用期间启动的子代理会在后台运行，而不是前台。
